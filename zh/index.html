多数工具是每屏截一张再拼起来，遇到现代网页就会出错。这个扩展逐一处理这些情况。

只要三步。

扩展工作时，页面会自己滚动。

1

开始

点击工具栏图标并选择“截取整页”，或在页面上右键，或按 Alt Shift P。

2

稍等片刻

在弹窗、角标或标签页标题里看百分比。

3

编辑并保存

预览标签页会打开你的图片。需要的话先标注，然后保存 PNG。

你的页面仍然属于你。

没有任何内容会被发送出去。

  • 无需账号，没有服务器，没有统计，也不做跟踪。扩展自身不发起任何网络请求。
  • 截图在你的浏览器里生成，在你关闭预览标签页时删除，最迟在浏览器下次启动时删除。
  • 扩展只作用于你启动它的那个标签页。
每项权限的用途
activeTab、scripting在你选定的标签页里运行截图脚本。
downloads把完成的 PNG 保存到你的电脑。
storage、unlimitedStorage把较大的图片从截图过程传给预览标签页。
contextMenus在右键菜单里加入“截取整页”。
tabs打开预览标签页，读取页面标题作为文件名，并在无法截取的页面上让图标变灰。
webNavigation在嵌入内容的页面里找到可滚动的框架。
注意事项
  • 浏览器内部页面（chrome://）和 Chrome 应用商店无法截取，这是 Chrome 的限制。
  • 要截取本地文件，请为扩展打开“允许访问文件网址”。
  • 截取在页面高度达到 30,000 CSS 像素或用时 60 秒时停止（以先到者为准），并会提示你。
  • 动画很多的页面，以及只在你用鼠标滚动时才显示内容的网站，可能与实际页面有差异。

何不把它全截下来？

在任意页面按 Alt Shift P，其余的交给它。
